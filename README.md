# ✨ Keyword Extractor by **Dalfy**

> A smart and flexible tool to extract the most important words from a text using base rules and customizable settings.

---

## 🚧 Work in Progress

This package is **currently in development and not yet usable**.

---

## 🎯 Goal of the project

The aim of this library is to provide a simple yet powerful way to:

- Analyze a text
- Identify its most relevant words or expressions
- Apply **base rules**
- Fine-tune the results through **adjustable settings**

Instead of relying on a fixed algorithm, the tool is designed to be **configurable**, so you can adapt it to different use cases.
